bounty on [make.fun](https://make.fun): a program that writes the funniest
one-line code review comment that approves a pull request with quiet
existential dread.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes a single line of at most 140 characters to
`/output/entry.txt`. No network, no secrets, no dependencies beyond
Python 3.
